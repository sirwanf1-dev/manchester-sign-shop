# Manchester Sign Shop

Mobile-first Astro website for Manchester Sign Shop.

## Real project photos

Add photos to `public/images/real-images/`.

Use:
- `real-image-1.jpg`
- `real-image-2.jpg`
- ...
- `real-image-10.jpg`

The build automatically detects existing JPG, JPEG, PNG and WEBP files and displays only those that exist.

## Zoomable slideshow

Tap a project photo to open the full-screen gallery.

- Swipe left/right on mobile
- Pinch to zoom
- Double-tap to zoom
- Drag while zoomed
- Mouse controls on desktop
- Arrow keys and Escape key
- High-resolution source images are used directly

The existing `manchester` project is separate from this repository.
