# Manchester Sign Shop

Mobile-first Astro website for Manchester Sign Shop.

## Real project photos

Add photos to:

`public/images/real-images/`

Use these names:

- real-image-1.jpg
- real-image-2.jpg
- ...
- real-image-10.jpg

The website detects existing photos automatically and displays only those that exist.

Tapping a project photo opens the full-screen zoomable gallery with swipe navigation, pinch zoom, double-tap zoom and desktop controls.
